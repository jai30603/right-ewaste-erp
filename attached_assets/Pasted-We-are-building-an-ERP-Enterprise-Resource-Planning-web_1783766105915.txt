We are building an ERP (Enterprise Resource Planning) web application for a real company named "Right Ewaste Recycle Pvt. Ltd."

Technology Stack:
- Backend: Python Flask
- Database: SQLite
- Frontend: HTML, Bootstrap 5
- Architecture:
    - Routes (Blueprints)
    - Services
    - Repositories
    - SQLite Database

The Party module should be production-ready because it will be used by the company.

------------------------------------
OBJECTIVE
------------------------------------

Complete the Party Management module with full CRUD functionality and professional UI.

The Party module will maintain all Customers, Suppliers and Both.

The application should follow clean code principles.

4. Delete Party
------------------------------------

DO NOT permanently delete records.

Implement Soft Delete.

When Delete is clicked:

Show confirmation dialog.

Example:

"Are you sure you want to delete this party?"

If confirmed:

Update:

is_active = 0

Do not remove data from database.

Deleted parties should no longer appear in Party List.
