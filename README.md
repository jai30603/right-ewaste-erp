# Right Ewaste ERP

An internal ERP system built for Right Ewaste Recycle Pvt. Ltd.

## Features

- Company Management
- Party Management
- Material Management
- Sales Invoice
- Purchase Invoice
- Inventory
- Reports

## Technology Stack

- Python
- Flask
- SQLite
- Bootstrap 5

## Project Status

🚧 Under Development

## Run the app

From the project root:

```bash
python app.py
```

Or from the backend folder:

```bash
cd backend
python app.py
```

The app will be available at http://127.0.0.1:5000
